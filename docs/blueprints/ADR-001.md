# ADR-001 — Princípios Arquiteturais

## Status

Aprovado.

## Decisão

O Turistei será modelado como um ecossistema modular, moderno e escalável.

## Princípios

1. Local é a entidade central do sistema.
2. Existe apenas um ecossistema Turistei.
3. O Marketplace será uma evolução do Local.
4. Funcionalidades serão liberadas por Plano, Ownership e Permissões.
5. Supabase será o backend oficial.
6. React 19, TanStack Start e Lovable permanecem como base tecnológica.
7. O legado serve apenas como referência de negócio.
8. O sistema deve nascer preparado para múltiplas cidades.
9. Segurança será baseada em Supabase Auth, RLS e Edge Functions.
10. A arquitetura deve evitar retrabalho e permitir evolução incremental.

## Consequência

Toda decisão técnica futura deve respeitar este ADR.
